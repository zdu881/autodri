# 本科科研项目总结

## 项目名称

面向自然驾驶视频的驾驶员注视与行为监测分析系统

## 一、项目背景

驾驶员状态监测是智能交通、主动安全和自然驾驶行为研究中的重要组成部分。真实道路环境下的车内视频具有光照变化大、驾驶员个体差异明显、车辆与摄像头布局不统一、短时遮挡和无效帧较多等特点。单纯依赖通用模型进行逐帧识别，往往难以稳定适应新驾驶员、新车辆和新采集场景。

本项目围绕学校科研计划中的自然驾驶视频数据，构建了一套代码化、可复核、可扩展的驾驶员注视与行为分析流程。项目重点不在于重新设计底层视觉网络，而在于将已有检测与分类模型组织成适合科研数据处理的工作流，完成从视频整理、ROI 定位、人工标注、few-shot 微调、片段推理到窗口级行为统计的闭环。

## 二、研究目标

本项目的核心目标是为自然驾驶研究提供稳定的驾驶员状态分析能力，具体包括：

1. 从车内视频中识别驾驶员注视状态，主要标签包括 `Forward`、`Non-Forward`、`In-Car` 和 `Other`。
2. 建立面向新驾驶员、新车辆场景的 few-shot 快速适配流程，降低新域数据标注成本。
3. 将帧级识别结果进一步聚合为窗口级行为指标，便于后续驾驶行为研究使用。
4. 提供人工标注、ROI 复核、质量检查和结果汇总工具，使整个流程可追踪、可复现。

## 三、主要工作内容

### 1. 项目工程化整理

项目被整理为可安装的 Python 包 `autodri`，并保留旧脚本路径作为兼容入口。核心代码位于 `src/autodri/`，包括注视识别、手握方向盘检测、数据准备、标注、训练、推理和指标统计等模块。项目通过 `${AUTODRI_WORKSPACE}` 将代码与大规模视频、模型权重、实验输出分离，避免研究数据和生成产物污染代码仓库。

### 2. 注视状态识别流程

系统针对驾驶员区域视频进行注视状态识别。流程包括目标片段读取、ROI 裁剪、人脸检测、注视状态分类、结果 CSV 导出和后处理。注视标签体系中，`Other` 被用于吸收无效样本，例如 ROI 没有覆盖驾驶员、驾驶员不可见、画面异常或无法判断的情况。这一设计提高了真实自然驾驶数据下的鲁棒性。

### 3. 标注与 few-shot 数据构建

项目提供了标注包构建和 Web 标注工具，支持从多域视频中按时间覆盖策略抽样，生成可人工标注的 ROI 裁剪图片。标注结果保存为 `labels.csv`，可继续转换为分类训练数据。针对新参与者或新车辆场景，系统支持构建少量样本的 few-shot 包，并在已有模型基础上进行快速微调。

### 4. 跨域与泛化评估设计

项目文档中设计了跨驾驶员、跨车辆和跨数据域的验证方案。推荐评估指标包括 Top-1 Accuracy、Macro F1、每类 Recall，尤其关注 `Other` 类和长尾场景。对于新域适配，项目规划以 `Accuracy vs. Labeled Samples` 曲线展示少样本标注量与模型性能之间的关系。

### 5. 时间窗口与行为级统计

自然驾驶视频中的逐帧预测容易受到短时遮挡、光照变化和检测波动影响。因此项目实现了面向固定时间窗的统计流程，将高频帧级输出转化为行为级指标，例如 off-path 时间比例、glance rate、持续 off-path 事件次数，以及与 hand-on-wheel 输出联合得到的方向盘接触比例。这使模型结果能够服务于更高层的驾驶行为分析。

### 6. 手握方向盘检测与辅助行为信号

项目还包含 hand-on-wheel 推理流程，使用目标检测模型识别手和方向盘，并通过 IoU、迟滞规则和窗口投票判断 `ON/OFF/UNCERTAIN` 状态。该模块为注视状态之外的驾驶行为研究提供辅助信号，也为后续训练轻量化 student detector 留出了工程接口。

## 四、技术路线

项目整体技术路线可以概括为：

1. 读取研究计划表和目标视频，建立目标片段清单。
2. 对驾驶员区域进行 ROI 定位与复核，处理双窗口或单窗口布局差异。
3. 从目标视频中抽样生成标注包，并通过 Web 工具进行人工标注。
4. 将标注数据转换为分类训练集，构建 participant-specific few-shot 子集。
5. 基于 YOLOv8-cls 等成熟模型进行微调，并导出 ONNX 推理模型。
6. 对目标驾驶片段运行注视与手握方向盘推理。
7. 按固定时间窗口聚合帧级结果，输出可解释的驾驶行为统计表。

## 五、阶段性成果

本项目已形成较完整的研究型代码仓库和工作流，主要成果包括：

- 建立了 `autodri` Python 包结构，提供稳定的命令行入口。
- 实现了驾驶员注视识别、手握方向盘检测、ROI 分配、人工标注、few-shot 数据准备、模型训练、片段推理和窗口级指标统计流程。
- 编写了多份项目文档，包括标注说明、支持的工作流、跨域数据计划、PERCLOS 与眨眼指标说明、poster 方案和论文方法草稿。
- 将帧级视觉模型输出转化为窗口级行为指标，增强了结果的研究可解释性。
- 明确了后续实验协议，避免只报告单一总体准确率，而是从新域适配、时序稳定性和行为统计三个层面评价系统。

## 六、项目创新点与价值

本项目的创新性主要体现在科研工作流层面：

1. 将真实自然驾驶数据中的 ROI 错误、无效帧和跨域差异显式纳入处理流程，而不是假设输入视频已经完全干净。
2. 采用 participant-specific few-shot adaptation 思路，使系统能够用少量新域标注数据快速校准到新驾驶员和新车辆。
3. 将 `Other` 类作为部署鲁棒性的一部分，用于吸收不可判定或不适合训练的样本。
4. 将逐帧识别结果进一步转化为窗口级行为统计，使输出更适合自然驾驶行为研究，而不仅是模型分类结果。
5. 通过代码包、CLI、文档和兼容脚本组织项目，提高了科研代码的可复现性和可维护性。

## 七、个人参与与能力提升

作为本科生科研计划的一部分，本项目训练了从算法理解到工程落地的完整能力。项目过程中涉及 Python 工程组织、视频处理、模型推理、数据标注、实验设计、结果汇总和技术文档撰写等工作。通过该项目，我对真实科研项目中“模型精度、数据质量、工程流程和结果解释”之间的关系有了更具体的理解，也认识到实际应用中的关键问题往往不仅是模型本身，还包括数据入口、质量控制和可复现流程。

## 八、不足与后续计划

当前项目仍处于研究工程持续完善阶段，主要不足包括：

- 部分实验结果仍依赖本地数据和模型权重，公开仓库中不包含原始视频和大模型文件。
- 完全零样本跨域泛化能力仍有限，需要进一步通过公共数据集和新参与者数据验证。
- `Other` 类样本和长尾场景仍需持续补充，以提高自然驾驶复杂环境下的稳定性。
- 手握方向盘模块目前仍可进一步轻量化，以提升大规模视频处理效率。

后续工作将重点补充跨驾驶员、跨车辆和跨光照条件下的系统评估，完善 few-shot 适配曲线，并将当前窗口级统计结果进一步用于自然驾驶行为分析。
